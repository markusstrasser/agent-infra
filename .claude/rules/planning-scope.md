# Planning scope — think the full loops

Anchor: `decisions/2026-06-18-planning-lifecycle-contract.md`.

When proposing a plan, phase split, or "do only X":

1. **State the full loop** — what happens after this slice (verify, close, propagate, maintain).
2. **Name what you defer** — and whether deferral is operator taste vs missing input.
3. **Do not shrink scope to avoid uncertainty** — extend the divergent phase (constitution P5) or ask one targeted kickoff question.

Missing-input failures (exit undefined, scope unstated, closure inputs) are fixed at **kickoff elicitation**, not by adding execution instructions mid-task.

**Register split (do not conflate):**
- **Verify-first** — claims, evidence, irreversible moves.
- **Act-now** — work already authorized on reversible scope.
