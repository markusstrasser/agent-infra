## Caveats that matter for routing
1. **CursorBench contamination** — Cursor blog: earlier Cursor codebase snapshot
   accidentally in training; they exclude CursorBench from the launch table. Do not
   use CursorBench to promote Grok over Opus/GPT.
2. **Bare Cursor slug** — `--model grok-4.5` resolves to **fast-xhigh**, not a neutral
   default. Always pass an explicit effort slug (`grok-4.5-xhigh` preferred for critique).
3. **xAI API key blocked** — not an EU geo issue (Chicago Mullvad still 403). Cursor
   pool / critique `grok` axis is the live surface until the key is rotated/unblocked.
4. **Critique `grok` ≠ `llmx -p cursor`** — model-review uses `cursor-agent --workspace`;
   llmx cursor transport is packet-only (empty cwd).
