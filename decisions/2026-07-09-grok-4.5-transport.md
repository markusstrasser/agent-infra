# 2026-07-09: Grok 4.5 — transport + named niche (not Default Routing)

## Context
SpaceXAI released Grok 4.5 (2026-07-08): pitched as Opus-class, jointly trained with
Cursor, $2/$6 base ($4/$18 fast), 500k context, reasoning low/medium/high. Operator
scope this session: **1B** (transport + registry + model-guide stub), **2C** (Cursor +
xAI), **3C** (role — grounded same day via AA paste + critique-axis wire).

## Alternatives considered
1. **Full promote now** (default routing + always-on critique axis) — rejected: no
   independent bakeoff at wire time; CursorBench contaminated per Cursor's own blog;
   xAI API key blocked. Later AA board still does not justify replacing Opus/GPT defaults.
2. **Cursor-only wire** — rejected: operator asked both surfaces; API path is priced and
   defaulted even if live smoke fails today.
3. **Transport + stub only, then named niche (chosen)** — callable everywhere we can
   reach; Default Routing unchanged; opt-in `grok` critique axis + scout-model override.

## Counterevidence / probes
- Cursor: `cursor-agent models` lists `grok-4.5-{medium,high,xhigh}` + fast variants;
  live ask-mode smoke returned `OK`. Bare `--model grok-4.5` aliases to
  `grok-4.5-fast-xhigh` (footgun).
- xAI API: key present but HTTP 403 `API key is currently blocked`. Egress verified
  Chicago US (Mullvad) — **key status, not EU geo**. Dry-run routing works; live
  completion blocked until key rotated/unblocked.
- Pre-existing: `composer-2.5` was also blocked by `LITE_ALLOWED_MODELS` on the default
  Cursor subscription path — fixed in the same allowlist edit (additive, not a role
  change).
- AA Intelligence Index v4.1 (2026-07-08 paste): Intelligence **54** (frontier pack),
  Coding **72**, AutomationBench lead **51%**, cost/task ~$0.31; non-hallucination
  ~**46%**, CritPt **15%** — capability ≠ calibration.

## Decision
1. **Transport — integrated.** llmx xAI default → `grok-4.5`; PRICING + CONTEXT_WINDOW;
   `MODEL_RESTRICTIONS` low/medium/high; Cursor effort-suffixed slugs infer `cursor`;
   lite allowlist adds `grok-4.5` + `composer-2.5`. agent-infra `usage-check.py` vendors
   the same PRICING (drift-tested).
2. **Critique axis — repo-grounded `grok` (opt-in).** `--axes …,grok` dispatches
   `cursor-agent --mode ask --model grok-4.5-xhigh --workspace <project>` (same class as
   premise_scout). **Not** llmx `-p cursor` (neutral empty cwd = packet-only). Profile
   `grok_review` in `skills/shared/llm_dispatch.py`.
3. **Default Routing — still no.** Named niche only (model-guide). Use more: PLAN
   `--axes …,grok`, AutomationBench/τ³ tool loops, cheap frontier second opinion. Use
   less: unsourced facts, CritPt-hard physics, sole architecture judge, >500k context.
4. **Scout recipes — model override, not a new backend.** `debug-until-dry` /
   `adversarial-debug-scout` stay on backends `cursor|codex|claude`; pass
   `--scout-backend cursor --scout-model grok-4.5-xhigh` for Grok lens diversity.
5. **xAI API 403 — key blocked, not EU.** Rotate/unblock `XAI_API_KEY` in console.
