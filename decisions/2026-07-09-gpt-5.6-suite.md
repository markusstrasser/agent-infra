# Decision: GPT-5.6 suite as OpenAI default (GPT-5.5 removed)

**Date:** 2026-07-09  
**Status:** accepted  
**Scope:** llmx transport + skills dispatch + agent-infra cost mirrors

## Context

OpenAI GA'd the GPT-5.6 family on 2026-07-09: **Sol** (flagship), **Terra** (mid), **Luna** (cheap/fast). API IDs: `gpt-5.6-sol` (alias `gpt-5.6`), `gpt-5.6-terra`, `gpt-5.6-luna`. List rates $5/$30, $2.50/$15, $1/$6 per MTok. Effort adds `max` beyond `xhigh`. "Pro" is `reasoning.mode=pro` on the same model id, not a separate slug.

Operator read: **Luna ≈ prior GPT-5.5 performance at roughly half that price** ($1/$6 vs the old $5/$30 class). No reason to keep GPT-5.5 as a live route, upgrade target, or pricing key.

## Decision

1. **Default OpenAI model** in llmx = `gpt-5.6-sol` (provider default + bare `gpt-5.6` → Sol).
2. **Dispatch profiles:** `formal_review` → Sol; `gpt_general` → **Luna**; `mechanical_review` → Luna (low effort). Terra is mid-tier opt-in only.
3. **GPT-5.5 fully removed** from MODEL_RESTRICTIONS, known-models, PRICING, CONTEXT_WINDOW, upgrades, and routing docs. Passing `gpt-5.5` is an unknown/typo path — not auto-upgraded.
4. **Effort:** pass `max` through for GPT-5.6 on API/codex; map `max`→`xhigh` for older GPT models (5.4 and earlier).
5. **Do not** invent `gpt-5.6-sol-pro` as a model id.

## Consequences

- Everyday critique GPT cost drops to Luna rates; Sol reserved for formal/cross-lab/hard Codex.
- Subscription path remains `codex-cli` via `llmx chat --subscription`.
- Historical usage-log rows that still say `gpt-5.5` estimate as unpriced ($0) until re-keyed — acceptable; no silent wrong rate.
- Regenerate: `llmx info --write-mirror`.
